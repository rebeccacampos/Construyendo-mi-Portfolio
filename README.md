# 💻 Construyendo mi Portfolio — Proyecto Práctico UD2

Desarrollo de mi portfolio web personal aplicando HTML5 semántico y CSS3 moderno, partiendo de la identidad visual y el prototipo diseñados en la Unidad Didáctica 1.

Este repositorio documenta paso a paso la evolución del proyecto, desde la estructura base hasta su adaptación responsive y versión para impresión.

---

## 🎯 Objetivos del Proyecto
* Transformar el diseño conceptual de la UD1 en una web funcional de dos páginas interconectadas (`index.html` e `interior.html`).
* Aplicar estándares de semántica HTML5, formularios con validación nativa y arquitectura CSS modular (`@import`).
* Implementar técnicas actuales de maquetación con **Flexbox**, **CSS Grid** y **Media Queries**.

---

## 📁 Estructura del Repositorio

```text
construyendo-mi-portfolio/
├── index.html          # Página principal 
├── interior.html       # Página secundaria 
├── css/
